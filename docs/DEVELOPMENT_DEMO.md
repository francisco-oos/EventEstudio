# Entorno de demostración

Sólo para desarrollo local. `npm run seed` crea:

- propietario: `owner@eventstudio.local` / `Cambiar123!`
- cliente: `client@eventstudio.local` / `Cambiar123!`

El seed está bloqueado cuando `NODE_ENV=production`. Las credenciales no deben copiarse a variables, respaldos ni despliegues reales.
