EVENTSTUDIO 6.15.0-rc.34 — INICIO DE QA
========================================

RC34 corrige los hallazgos del test físico de RC33:
- contraste semántico de texto en Recipes;
- apertura/experiencia como recomendador y override, sin Guardar entrada paralelo;
- nombres largos sin corte dentro de palabras;
- protección API al aplicar Recipes comerciales.

ARRANQUE
-------
1. npm ci
2. Copiar .env.example a .env y configurar sólo el entorno local.
3. En QA_CON_DATOS: NO ejecutar `npm run seed`; iniciar con `npm start`.

PRUEBA OBLIGATORIA ANTES DE PRODUCCIÓN
--------------------------------------
npm run test:preproduction
npm audit --audit-level=moderate
