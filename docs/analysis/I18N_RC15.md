# Internacionalización del panel — RC15

## Problema

El selector de idioma traducía navegación y algunos títulos, pero muchos textos estáticos y elementos generados después seguían en español. Además, conservar referencias a nodos de texto podía hacer que un cambio posterior tomara una traducción como fuente.

## RC15

- `UI_COPY` continúa siendo la fuente de navegación y zonas críticas.
- `STATIC_I18N` cubre etiquetas comunes del panel.
- `canonicalStaticSpanish()` recupera la clave canónica aunque el texto visible esté en inglés/portugués.
- `MutationObserver` vuelve a traducir contenido de interfaz generado dinámicamente.
- contenido del usuario/evento no debe traducirse automáticamente.

## Siguiente evolución

Migrar gradualmente cada módulo a claves semánticas (`i18n.t('commerce.product.status.hidden')`) y retirar frases hardcodeadas. No se incorporó una librería externa porque el panel actual puede evolucionar con un catálogo propio y sin aumentar el bundle.
