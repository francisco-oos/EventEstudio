# Showcase Gallery · RC13

## Objetivo

Dar una muestra visual rápida de la calidad de EventStudio sin obligar al visitante a leer una explicación extensa.

## Implementación

- página `public/showcase.html`;
- composición tipo masonry/Pinterest;
- filtros de evento;
- demos Daisy Atelier;
- CTA a catálogo/sandbox;
- eventos de conversión.

## Privacidad

Los elementos seed son `source_type='demo'` y se etiquetan como **Demo editorial**. Ningún evento de cliente entra automáticamente al Showcase.

Para una futura muestra real se exige consentimiento y un snapshot sanitizado: sin teléfonos, tokens, respuestas RSVP privadas, mensajes ni datos operativos innecesarios.
