# EventStudio 6.14.2-rc.22

- Motor SVG modular de sellos de cera con borde determinista, relieve, materiales y ornamentos.
- Estudio avanzado desacoplado del renderer público.
- Cinco plantillas y cinco aperturas de la integración visual anterior conservadas.
- RSVP configurable por evento sin hacer depender el enlace público de una lista de invitados.
- Enlace público visible y copiable desde el panel.
- Datos bancarios totalmente opcionales y no renderizados cuando están vacíos o desactivados.
- Openpay opcional para regalos con tokenización en cliente y persistencia de contribuciones.
- Pruebas RC22 y documentación de arquitectura añadidas.
