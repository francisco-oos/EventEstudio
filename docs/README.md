# Documentación de EventStudio

Toda la documentación se concentra bajo `docs/`; la raíz de `docs/` conserva únicamente este índice.

- `analysis/`: decisiones, investigaciones, referencias y arquitectura.
- `audits/`: auditorías por release candidate.
- `backlog/`: trabajo futuro aprobado o diferido.
- `checklists/`: listas operativas para publicación, QR, fotos, etc.
- `guides/`: operación, despliegue, respaldo, WhatsApp y pruebas.
- `indexes/`: índice documental de cada línea candidata.
- `labs/`: pruebas aisladas que no forman parte de producción.
- `release-notes/`: historial de cambios.
- `security/`: decisiones y revisión de seguridad.
- `traceability/`: requisito → implementación → evidencia → estado.
- `validation/`: pruebas ejecutadas, bloqueadas y pendientes.

Referencia vigente: `indexes/INDEX_DOCUMENTACION_RC21.md`.

Los documentos históricos se conservan porque registran decisiones y regresiones previas; no deben interpretarse como la fuente de verdad de la versión actual cuando contradigan un documento RC21.
