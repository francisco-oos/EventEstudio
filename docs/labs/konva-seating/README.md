# Konva Seating PoC

Laboratorio aislado, no cargado por EventStudio.

- Abre `index.html` con conexión a Internet; importa Konva desde jsDelivr únicamente para el PoC.
- Permite mesas redondas/rectangulares, arrastre, snap, pan y pinch zoom.
- No persiste datos ni toca la base de EventStudio.
- Si el PoC supera la comparación, la integración real deberá usar paquete fijado/local y un `KonvaSeatingAdapter`; no se dejará CDN en producción.
