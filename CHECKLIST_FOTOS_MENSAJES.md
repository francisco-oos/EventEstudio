# Checklist de fotos y mensajes

- [ ] Evento publicado y módulo de carga habilitado.
- [ ] QR abre el slug y mesa esperados.
- [ ] JPEG, PNG, WebP y HEIC válidos aceptados; archivo falso rechazado.
- [ ] Límite de 20 archivos y tamaño por archivo comunicado.
- [ ] Reintentar el mismo lote no duplica registros.
- [ ] Nombre y mensaje son opcionales y respetan límites.
- [ ] Lotes nuevos quedan pendientes.
- [ ] Fotos pendientes no tienen URL pública directa.
- [ ] Administrador puede abrir, aprobar, ocultar y eliminar.
- [ ] Sólo mensajes aprobados aparecen en la invitación.
- [ ] Eliminación retira registro y archivo; lote vacío se limpia.
- [ ] Respaldo incluye originales y base de moderación.
- [ ] Probar red móvil lenta antes del evento.
