EventStudio RC19 conserva las referencias CSS de las tipografías locales.

Este paquete de intercambio no redistribuye archivos binarios de fuentes. Para
conservar exactamente la tipografía de una instalación autorizada anterior,
copia sus archivos de public/fonts/ antes de la prueba visual final. Si no los
copias, el navegador utilizará las familias de respaldo definidas en CSS.
